# Pizza-Sales
The dataset includes sales transaction and client's scope and limitation for report
📊 Project Overview
This project analyzes pizza sales data to identify key performance metrics and business insights.
The dataset includes detailed sales transactions and information provided by the client, along with the scope and limitations defined for this report.
The aim to replicate the result in SQL through Power Bi added with visuals.

🎯 Objectives
The goal of this project is to create data-driven insights using SQL and Power BI, focusing on:
•	Key Performance Indicators (KPIs)
•	Daily & Monthly Trends for Orders
•	% Sales by Pizza Category
•	% Sales by Pizza Size
•	Total Pizzas Sold
•	Top & Bottom Pizzas by Revenue

🛠️ Tools Used
•	SQL Server Management Studio (SSMS) – for data extraction and analysis
•	Power BI Desktop – for interactive data visualization

📈 Process
	**Data Preparation**: Cleaned and explored the dataset in SQL Server.
	**Analysis**: Wrote SQL queries to calculate KPIs and identify sales patterns.
	**Visualization**: Replicated SQL results into Power BI visuals to create a dynamic dashboard.

🚀 Insights & Highlights
•	Identified top-performing pizzas contributing the most to total revenue.
•	Compared daily and monthly sales trends to spot peak performance periods.
•	Analyzed customer preferences by pizza category and size.
